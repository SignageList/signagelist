# {{ .Site.Title }}

> {{ .Site.Params.description }}

SignageList is a hand-curated open directory of {{ len $products }} digital signage software products, {{ len $active }} of them currently active. Every listing is a structured record covering pricing plans, supported playback platforms, delivery model (cloud, on-premise, hybrid, self-hosted), headquarters, founding year, licensing, compliance certifications, and developer surface (API, CLI, MCP, SSO, SAML). Records are maintained by hand from vendor sources rather than scraped, and each carries a last-verified date.

The directory is edited by 514sid, who works in the digital signage industry. Corrections and additions go through GitHub issues and pull requests at {{ .Site.Params.githubRepo }}.

Last updated: {{ .Site.Lastmod.Format "2006-01-02" }}

## Record schema

Each product record uses these fields:

- name, slug, description, website
- year_founded (integer or null), headquarters (list of country or city strings)
- categories (CMS, Content provider, Computer vision), platforms (list of playback platforms)
- open_source (boolean), license (SPDX identifier or null), source_code_url
- models: a list of delivery models, each with delivery (cloud, on-premise, hybrid, self-hosted), free_trial, has_freemium, pricing_available, and pricing plans carrying name, payment_model, billing_basis (per_device, per_user, per_location, flat_rate), monthly, yearly, included_screens, overage_per_screen, max_screens
- has_api, developer_portal_url, has_docs, docs_url, has_cli, has_mcp, has_sso, has_saml, self_signup
- compliance: soc2, iso27001, hipaa, cra, fedramp (booleans)
- stats.screens: total, source, date
- discontinued (boolean), notes, features, integrations, last_verified
